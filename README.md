# Проект Дашборд для анализа электронной коммерции в Superset

## Бизнес-контекст

Новый директор отдела продаж поставил задачу - разработать дашборд для анализа электронной коммерции. После уточнения требований на интервью были определены ключевые направления: продажи и поведение пользователей.

Дашборд предназначен для отслеживания динамики продаж, эффективности товаров и вовлечённости пользователей, чтобы принимать решения на основе данных.

---

## Цель проекта

Разработать работающий дашборд в Apache Superset для анализа электронной коммерции: продажи, продукты, пользовательское поведение - с фильтрами, Jinja-метриками и единым визуальным стилем.

---

## Ключевые метрики

**Продажи:**
- количество заказов;
- общая выручка;
- средний чек;
- средняя стоимость заказа;
- количество уникальных покупателей;
- средний доход на сессию;
- количество продуктов;
- количество сессий;
- средняя длина сессии;
- время до первого заказа.

**Продукты:**
- топ-10 товаров по выручке;
- средний чек;
- распределение по категориям.

**Пользователи:**
- время сессии;
- распределение по операционным системам;
- база и активная база;
- MAU, MoM, YoY;
- конверсия в пользовательский путь.

---

## Структура дашборда

### Вкладка «Основные метрики»
- Карточки: уникальные покупатели, конверсия в заказ, средний доход на сессию.
- График площадей или карточки: количество продуктов, общая выручка, средний чек.

### Вкладка «Продажи»
- Круговая диаграмма по каналам продаж.
- Динамика по операционным системам.
- Продажи по категориям товаров.
- Таблица продаж по категориям (последний день / среднее за 7 и 32 дня).
- Таблица с поиском по товарам.

### Вкладка «Аналитика пользователей»
- Динамика базы и активной базы пользователей.
- Таблицы: MAU, MoM, YoY.
- Поведение активных пользователей по девайсам: объём посещений и среднее время сессии.
- Конверсия в пользовательский путь: конверсия в заказ и время до первого заказа.

---

## Фильтры

- Период (по умолчанию с 2024-01-01) - не влияет на таблицу активных и таблицу по категориям.
- Месяц для Jinja (по умолчанию 2024-12-01) - только для таблицы активных и таблицы по категориям.
- Категории товаров - на все графики.
- OS - на все графики.

---

## Стек технологий

- **Apache Superset** - дашборд, чарты, фильтры, Jinja.
- **PostgreSQL** - источник данных.
- **SQL** - объединение таблиц и расчёт метрик.

---

## Ключевые результаты

- Создан единый датасет и промежуточные CTE.
- Разработан дашборд с тремя вкладками: метрики, продажи, аналитика пользователей.
- Настроены фильтры, Jinja-метрики (MoM, YoY) и единый визуальный стиль.
- Подготовлена аналитическая записка с выводами и рекомендациями.
